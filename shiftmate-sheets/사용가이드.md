# ShiftMate Google Sheets 사용 가이드

## 📦 설치 (딱 한 번만 하면 됩니다)

### 1단계: Google Sheets 열기
1. [sheets.google.com](https://sheets.google.com) 접속
2. 새 스프레드시트 만들기 클릭

### 2단계: Apps Script 붙여넣기
1. 상단 메뉴 **확장 프로그램 → Apps Script** 클릭
2. 기존 코드 전체 삭제
3. `Code.gs` 파일 내용을 전부 복사해서 붙여넣기
4. 💾 저장 버튼 클릭 (또는 Ctrl+S)
5. 브라우저 탭 닫고 스프레드시트로 돌아오기

### 3단계: 초기 설정 실행
1. 스프레드시트 새로고침 (F5)
2. 상단 메뉴에 **📋 ShiftMate** 메뉴가 생김
3. **📋 ShiftMate → 1️⃣ 전체 시트 초기 설정** 클릭
4. 권한 요청이 뜨면 **허용** 클릭
5. "설정 완료" 알림 → 확인

## 📋 매일 사용법

### 직원 등록
1. **📋 직원목록** 시트 클릭
2. B열에 이름, C열에 전화번호, D열에 조(A조/B조) 선택
3. E열 직책, F열 입사일, H열 재직여부 선택

### 스케줄 생성 (월 초에 한 번)
1. **📋 ShiftMate → 📅 이번 달 스케줄 생성** 클릭
2. 자동으로 A조/B조 주간·야간 배치 완료
3. 수동으로 바꾸고 싶은 날짜는 직접 "주" 또는 "야" 수정

### 출결 기록 (매일)
1. **✅ 출결기록** 시트 클릭
2. 새 행에 입력:
   - A열: 날짜 (예: 2025-02-20)
   - B열: 이름
   - C열: 조 (A조/B조)
   - D열: 근무유형 (주간/야간)
   - E열: 출근시간 (예: 08:05)
   - F열: 퇴근시간 (예: 20:10)
   - K열: 상태 (정상/지각/조기퇴근/결근)

### 현황 확인
- **📊 대시보드** 시트: 이번 달 전체 요약 확인
- **📋 ShiftMate → 📊 대시보드 새로고침** 클릭

### 월말 정산
- **📋 ShiftMate → 📤 이번 달 출결 현황 출력** 클릭
- 직원별 주간/야간/결근/지각/초과근무 집계 자동 생성

## ⚠️ 자주 묻는 질문

**Q: 주간/야간 시간이 우리 공장과 다르면?**
A: Apps Script에서 `CONFIG` 부분의 `start`/`end` 시간을 수정하세요.

**Q: 교대 주기가 격주가 아니라 매일 교대이면?**
A: Apps Script의 `ROTATION_WEEKS`를 0으로 설정하세요.

**Q: 직원이 조를 바꾸면?**
A: 직원목록에서 D열(조)을 수정하고, 스케줄을 다시 생성하세요.
