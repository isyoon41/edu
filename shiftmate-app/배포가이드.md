# ShiftMate 웹앱 배포 가이드
## 비개발자도 30분 안에 완성 가능

---

## 필요한 것 (모두 무료)
- Gmail 계정 1개
- 스마트폰 또는 컴퓨터

---

## 1단계: Supabase 데이터베이스 만들기 (10분)

**Supabase = 데이터를 저장하는 창고 (무료)**

1. [supabase.com](https://supabase.com) 접속 → **Start for free** 클릭
2. Google 계정으로 로그인
3. **New project** 클릭
   - 이름: `shiftmate`
   - 비밀번호: 기억할 수 있는 비밀번호 입력
   - 지역: **Northeast Asia (Seoul)** 선택
4. 프로젝트 생성 완료 (1~2분 대기)

5. 왼쪽 메뉴에서 **SQL Editor** 클릭
6. `supabase/schema.sql` 파일 내용을 전부 복사해서 붙여넣기
7. **Run** 버튼 클릭 → "Success" 메시지 확인

8. 왼쪽 메뉴 **Settings → API** 클릭
9. 아래 두 값을 메모장에 복사해두기:
   - `Project URL` → 예: https://abcdef.supabase.co
   - `anon public` → 길고 복잡한 문자열

---

## 2단계: Vercel에 웹앱 올리기 (10분)

**Vercel = 웹앱을 인터넷에 올려주는 서비스 (무료)**

### GitHub에 코드 올리기
1. [github.com](https://github.com) 접속 → 로그인 (없으면 회원가입)
2. 오른쪽 위 **+** 클릭 → **New repository**
3. Repository name: `shiftmate-app`
4. **Create repository** 클릭

5. 컴퓨터에 Git이 없으면 [git-scm.com](https://git-scm.com) 설치

6. 터미널(Mac: 터미널, Windows: 명령 프롬프트) 열고:
```bash
cd shiftmate-app
git init
git add .
git commit -m "ShiftMate 초기 버전"
git remote add origin https://github.com/내아이디/shiftmate-app.git
git push -u origin main
```

### Vercel에 배포
1. [vercel.com](https://vercel.com) 접속 → GitHub으로 로그인
2. **Add New → Project** 클릭
3. `shiftmate-app` 저장소 선택 → **Import**
4. **Environment Variables** 섹션에서:
   - `NEXT_PUBLIC_SUPABASE_URL` = 1단계에서 복사한 Project URL
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = 1단계에서 복사한 anon public key
5. **Deploy** 클릭 → 2~3분 대기
6. 배포 완료! `shiftmate-app.vercel.app` 같은 주소로 접속 가능

---

## 3단계: 직원 등록하기

1. Supabase → **Table Editor → workers** 클릭
2. **Insert row** 클릭해서 직원 정보 입력:
   - `name`: 이름 (예: 홍길동)
   - `phone`: 전화번호
   - `pin_hash`: 4자리 PIN (예: 1234)
   - `group_name`: A조 또는 B조
   - `role`: worker (작업자) / line_leader (조장) / manager (관리자)
3. 모든 직원 입력 완료

---

## 4단계: 스케줄 생성

1. 웹앱 주소 접속 → **관리자 메뉴**
2. **스케줄 관리** → **이번 달 스케줄 생성** 클릭
3. 완료!

---

## 일상적인 사용

### 작업자가 출근할 때
1. 공장 태블릿이나 키오스크에서 웹앱 주소 접속
2. **출퇴근 체크인** 클릭
3. 이름 검색 → PIN 입력 → 완료

### 관리자가 확인할 때
1. 웹앱 주소 접속 → **관리자 메뉴**
2. 대시보드에서 오늘 출근 현황 확인
3. 출결 현황 메뉴에서 상세 기록 확인

---

## 자주 묻는 질문

**Q: PIN을 잊어버린 직원이 있으면?**
A: Supabase → workers 테이블에서 해당 직원 pin_hash 수정

**Q: 직원이 퇴사하면?**
A: Supabase → workers 테이블에서 `is_active`를 false로 변경

**Q: 주소가 너무 길어서 불편해요**
A: Vercel에서 도메인 연결 가능 (연 1~2만원)

**Q: 작업자들이 스마트폰으로 체크인해도 되나요?**
A: 네, 모바일 최적화되어 있습니다
